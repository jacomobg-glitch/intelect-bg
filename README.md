# Еволюция на ума

Офлайн PWA за математика, когнитивни игри и рефлекси. Без регистрация, сървър, реклами, известия и серии. Всички данни остават на устройството.

**Адрес:** https://jacomobg-glitch.github.io/intelect-bg/

- [Архитектура, формули и прагове](docs/ARCHITECTURE.md)
- [Задачи за следващите етапи](docs/ROADMAP.md)

Нивата в приложението описват натрупана практика в самите задачи. Приложението не обещава ефект върху мозъка.

## Пускане на компютъра

Нужен е Node.js.

```
npm start
```

Отвори http://localhost:5173. Приложението не работи при директно отваряне на `index.html`, защото ES modules и service worker изискват сървър.

Други команди:

```
npm test            unit тестове
npm run precache    обновява списъка за офлайн; изпълнявай го след всяка промяна във файловете
npm run table       отпечатва таблицата с праговете
```

## Публикуване

Всяко качване в клон `main` минава през `.github/workflows/pages.yml`: пуска тестовете и публикува само файловете на приложението в GitHub Pages.

```
npm run precache
npm test
git add -A
git commit -m "Описание на промяната"
git push
```

Инсталирането и офлайн работата на телефона изискват HTTPS, затова там ползвай адреса от GitHub Pages, а не `http://192.168.x.x`. Сайтът е публичен, но съдържа само кода. Данните ти не напускат устройството.

## Инсталиране на телефон с Android

1. Отвори адреса в Chrome и изчакай страницата да се зареди.
2. Отвори менюто ⋮ на Chrome и избери опцията за инсталиране или добавяне към началния екран. Същото действие има и в Настройки на приложението, когато Chrome го предложи.
3. Отвори приложението веднъж от новата икона, докато имаш интернет. След това работи и без мрежа.

## Инсталиране на Windows

1. Отвори адреса в Chrome или Edge.
2. Използвай иконата за инсталиране в адресната лента или опцията за инсталиране в менюто на браузъра.
3. Приложението се появява в менюто „Старт“ и работи в собствен прозорец.

Инсталирането от `localhost` и това от GitHub Pages са две отделни приложения с отделни данни. За постоянна употреба ползвай адреса от GitHub Pages на двете устройства.

## Пренос между устройствата

Няма сървър, затова данните се пренасят с файл:

1. На едното устройство: Настройки → **Изтегли копие**.
2. Прехвърли файла, например през облачно хранилище, имейл или кабел.
3. На другото устройство: Настройки → **Зареди копие**.
4. Избери **Слей** (по подразбиране) или **Замени изцяло**. Таблицата показва какво има на устройството, какво във файла и какъв ще е резултатът за избрания начин.

Какво прави **Слей**:

| Данни | Правило |
|---|---|
| XP по всяка способност | по-голямата стойност |
| Лични рекорди | по-добрият |
| Отметки по теми | обединение |
| Дата на усвояване и срок за преговор | по-новата |
| Стъпка на еволюцията | преизчислява се от слетите данни и не пада под достигнатата |
| Тема и други настройки | остават тези на устройството |

Сливането взема по-голямата стойност, а не сбора. Ако една способност е тренирана и на двете устройства след последния пренос, по-малкият принос няма да се добави. Затова пренасяй копие, когато сменяш устройството.

**Замени изцяло** е за ново устройство или за връщане към старо копие.

Прави копие и преди да изтриеш данните на браузъра или да смениш телефона: няма сървър, от който прогресът да се възстанови.

## Тестов режим

Настройки → докосни 7 пъти **Версия**. Панелът дава временен XP и скокове по стълбата, за да видиш еволюцията и галерията. Бутонът **Излез и върни прогреса** връща реалния прогрес точно какъвто е бил.

Излез от тестовия режим, преди да изтриеш `js/dev/`. След изтриването изпълни `npm run precache`.
