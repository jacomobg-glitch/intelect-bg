# Текстове в детския режим

Генериран файл: обновява се с `npm run kid-texts` от `js/content/texts.js`. Не се редактира на ръка.

Детският профил вижда дясната колона. Принципите: кратки изречения и познати думи; хвали се усилието и начинът, не талантът; грешката е информация, не провал; без сарказъм, без натиск и без сравнения.

Общо 25 текста.

## Начален екран

| Ключ | Стандартен текст | Детски текст |
|---|---|---|
| `home.you` | Ти си {name}. | Сега си {name}. |
| `home.next` | Следва: {name}. | Следва {name}. |
| `home.obstacle.skill` | За {step} ти трябват още {xp} {skill} | Още {xp} {skill} и ставаш {step}. |
| `home.obstacle.any` | За {step} ти трябват още {xp} | Още {xp} и ставаш {step}. |
| `home.ready` | Готово за {step}. | Готов си за {step}! |
| `home.levelNote` | Нивото показва натрупана практика в задачите. | Нивото показва колко си упражнявал, а не колко си умен. |
| `home.continue` | Продължи тренировката | Продължи |

## Профил

| Ключ | Стандартен текст | Детски текст |
|---|---|---|
| `profile.most` | най-много практика | тук си се упражнявал най-много |
